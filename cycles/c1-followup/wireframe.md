# C1 · 界面线框

> v0.1 · 2026-11-06
> 组件基线：**Vant Weapp**。线框里出现的每个控件，都必须能在 Vant 里找到对应实现。

---

## 零、页面总览

| 屏 | 类型 | 谁用 | 说明 |
| --- | --- | --- | --- |
| S1 待办列表 | Tab 1 | 老师 | 只出现已核实、分给自己的 |
| S2 学员详情 | 子页 | 老师 | 话术 + 结果码 + 反馈入口 |
| S3 核实工作台 | Tab 1 | 老板 | 折叠式分组，就地展开，不跳页 |
| S4 我的 | Tab 2 | 两人 | 今日完成数 |

> Tab 1 是同一个位置，**按角色显示不同内容**：老师看到 S1，老板看到 S3。

**结果码文字必须与现有 `followup_log.py` 完全一致**（已续费/有意向/考虑中/没时间/不续/未接通/要顺延/已流失/其他）。

## 五、组件清单（对齐 Vant Weapp）

| 线框里的东西 | Vant 组件 |
| --- | --- |
| 顶部导航 | `van-nav-bar` |
| 进度条 | `van-progress` |
| 卡片 / 列表项 | `van-cell` + 自定义 cell |
| 折叠面板 | `van-collapse` |
| 结果码九宫格 | `van-grid` |
| 备注输入 | `van-field` type=textarea |
| 按钮 | `van-button` |
| 空态 | `van-empty` |
| 加载 | `van-loading` |
| 弹窗确认 | `van-dialog` |
| 轻提示 | `van-toast` |
| 老师选择器 | `van-action-sheet` |
| 下拉刷新 | `van-pull-refresh` |

> 想加任何控件，先确认 Vant 里有对应组件，否则这个需求进不了 C1。
