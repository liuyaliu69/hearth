# 08 · 小程序样式规范

> 建立：2026-11-11 · 适用于 `miniprogram/`
> 目的：**样式只有一个来源**。改一次令牌，全站生效；页面里不许出现颜色和字号字面量。

---

## 一、四层架构

```
miniprogram/
├── app.wxss                    ← 只做 @import，顺序固定
└── styles/
    ├── tokens.wxss             ① 令牌：颜色 / 间距 / 字号 / 圆角 / 阴影
    ├── base.wxss               ② 基础：页面底色、字体、容器、文字层级
    ├── components.wxss         ③ 组件：card / row / tag / btn / stat / empty
    └── utilities.wxss          ④ 工具：flex / 间距 / 对齐（少量）
```

导入顺序不能变：**令牌 → 基础 → 组件 → 工具**。
后面的层可以覆盖前面的，反过来就乱。

---

## 二、规则（违反即返工）

| # | 规则 |
| --- | --- |
| 1 | 页面 `wxss` **只写布局**（几列、对齐、特殊间距），不写颜色/字号/圆角 |
| 2 | 任何数值都必须来自 `var(--xxx)`，不许出现 `#FF6B35`、`28rpx` 这类字面量 |
| 3 | 新增视觉样式先问：这是「一次性布局」还是「可复用组件」？后者写进 `components.wxss` |
| 4 | 组件命名用 BEM-lite：`.card`、`.card__title`、`.btn--ghost` |
| 5 | 想要的样式 components 里没有 → 先补组件，不在页面里凑 |

## 三、令牌清单

### 颜色

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--c-brand` | `#FF6B35` | 品牌橙（火花），主按钮、强调 |
| `--c-brand-dark` | `#E8551F` | 按下态 |
| `--c-brand-weak` | `#FFF2EC` | 品牌浅底（选中格） |
| `--c-text` | `#1A1A1A` | 主文字 |
| `--c-text-2` | `#5C6066` | 次要文字（标签列） |
| `--c-text-3` | `#9AA0A6` | 弱化文字（说明、占位） |
| `--c-bg` | `#F4F5F7` | 页面底色 |
| `--c-surface` | `#FFFFFF` | 卡片/白块 |
| `--c-divider` | `#F0F1F3` | 分割线 |
| `--c-success` / `--c-warning` / `--c-danger` | `#12B76A` / `#F79009` / `#F04438` | 语义色 |
| `*-weak` | 对应的浅底 | 标签底色 |

### 间距（4 的倍数，只有 6 档）

`--sp-1: 8rpx` · `--sp-2: 16rpx` · `--sp-3: 24rpx` · `--sp-4: 32rpx` · `--sp-5: 48rpx` · `--sp-6: 64rpx`

### 字号（只有 6 档）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--fs-xs` | 22rpx | 标签、脚注 |
| `--fs-sm` | 26rpx | 辅助说明 |
| `--fs-md` | 30rpx | 正文 |
| `--fs-lg` | 34rpx | 卡片标题 |
| `--fs-xl` | 40rpx | 页面标题 |
| `--fs-2xl` | 56rpx | 大数字 |

### 圆角 / 阴影

`--r-sm: 8rpx`（标签）· `--r-md: 16rpx`（卡片/按钮）· `--r-lg: 24rpx` · `--r-pill: 999rpx`
`--shadow-card`：极浅一层；**不要给每个卡片加大阴影**，页面会显得脏。

## 四、组件清单

| 组件 | 类名 | 说明 |
| --- | --- | --- |
| 卡片 | `.card` + `.card-title` | 白底、16 圆角、极浅阴影 |
| 键值行 | `.row` + `.label` + `.value` | 自带分割线，最后一行自动去掉 |
| 标签 | `.tag` + `.tag--danger/warning/success/info/brand` | 小圆角、浅底深字 |
| 按钮 | `.btn` / `.btn--ghost` / `.btn--danger` / `.btn--sm` | 主按钮品牌色，次按钮白底描边 |
| 大数字 | `.stat__value` + `.stat__label` | 统计块用 |
| 空状态 | `.empty` + `.empty__title` + `.empty__desc` | 列表为空时 |
| 提示 | `.notice` / `.notice--danger` | 需要用户注意的说明 |
| 长文本 | `.code` | 话术、openid 这类等宽内容 |

## 五、怎么改整体风格

**只改 `styles/tokens.wxss`。** 例如把品牌色换成蓝色：

```css
--c-brand: #2E90FA;
--c-brand-dark: #1570CD;
--c-brand-weak: #EAF3FE;
```

三行改完，按钮、标签、选中格、强调数字全部跟着变。

## 六、常见错误

| 错误 | 为什么不行 |
| --- | --- |
| 页面里写 `color: #07c160` | 令牌改了它不跟着变，最后全站颜色不统一 |
| 卡片加 `box-shadow: 0 8rpx 24rpx` | 阴影太重会显脏；层次靠底色和分割线，不靠阴影 |
| 每个页面自己定义 `.btn` | 三套按钮三个手感 |
| 用 `style="..."` 内联写颜色 | 同上，且很容易和令牌打架 |
| 字号出现 25rpx / 27rpx | 没有节奏感；只用 6 档令牌 |
