## 二、项目目录约定（我们仓库里的样子）

```
miniprogram/
├── app.js              启动逻辑、全局登录
├── app.json            页面注册、tabBar、窗口配置
├── app.wxss            全局样式
├── project.config.json 项目配置（含 appid，别写死到 git 里）
├── config/
│   └── env.js          ★ dev / prod 环境切换
├── utils/
│   ├── request.js      wx.request 封装（带 token、统一错误）
│   └── auth.js         登录与 token 存储
└── pages/
    ├── health/         P0 诊断页：显示后端返回的一切
    ├── tasks/          C1 待办列表
    ├── member/         C1 学员详情
    └── me/             C1 我的
```

**`project.config.json` 里的 `appid` 会被提交到仓库**——这不敏感（AppID 是公开标识，AppSecret 才是密码）。
**AppSecret 永远不进小程序代码**，它只在后端环境变量里。

## 三、第一次导入项目

> 前提：P0.7 骨架已生成（`miniprogram/` 目录已有文件）。

1. 打开**微信开发者工具** → 登录（用小程序管理员扫码）
2. 左侧选 **小程序** → 点 **+**（导入项目）
3. 填三项：

| 字段 | 填什么 |
| --- | --- |
| 目录 | `E:\deepseek\study\hearth\miniprogram` |
| AppID | 你的企业小程序 AppID |
| 项目名称 | `Hearth 火花私域` |

**预期结果**：左侧出现 `pages/health` 页面，模拟器里显示出诊断页内容。

## 四、两个必做的设置（不做会一直报错）

### 4.1 关闭域名校验（本地开发必须）

**右上角「详情」→「本地设置」→ 勾选：**

- ✅ 不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书

不勾的后果：请求 `http://127.0.0.1:8080` 会被拦，控制台报
`不在以下 request 合法域名列表中`。

> 这个开关**只在开发者工具里有效**。真机预览（开发版）也有效。
> **体验版和正式版无效**，必须配真实域名。

### 4.2 真机调试要换 IP（最常见的坑）

手机上 `127.0.0.1` 指的是**手机自己**，不是你的电脑。

| 场景 | 用什么地址 |
| --- | --- |
| 模拟器（开发者工具内） | `http://127.0.0.1:8080` |
| 手机真机预览/调试 | `http://<电脑局域网IP>:8080` |

查电脑 IP：`ipconfig` → 找「IPv4 地址」，例如 `192.168.1.8`。

**同时要满足**：

1. 手机和电脑连**同一个 WiFi**
2. Windows 防火墙放行 8080（首次运行后端时如果弹窗，选「允许」）
3. 后端监听在 `0.0.0.0`（Spring Boot 默认就是）

改地址的地方：`miniprogram/config/env.js`，见下一节。

## 五、本地联调：环境切换

`miniprogram/config/env.js` 是我们唯一改地址的地方：

```js
// dev  : 模拟器直连本机后端（无 nginx 前缀）
// devip: 真机调试，换成你的电脑局域网 IP
// prod : 线上，走 nginx 的 /hearth/ 前缀
const ENV = 'dev'

const BASE_URL = {
  dev:   'http://127.0.0.1:8080',
  devip: 'http://192.168.1.8:8080',   // ← 改成你的局域网 IP
  prod:  'https://www.huohuawd.cn/hearth'
}[ENV]

module.exports = { ENV, BASE_URL }
```

**三种环境的区别**：

| ENV | 后端收到的路径 | 用途 |
| --- | --- | --- |
| `dev` | `/api/health` | 模拟器 |
| `devip` | `/api/health` | 手机真机 |
| `prod` | `/api/health`（nginx 剥掉 `/hearth/`） | 体验版 |

> 三种情况下**后端收到的路径完全一致**，所以本地验证过的路由在线上必然成立。
> 这是当初配本地 nginx 时的同一个道理。

### 可选：本地 nginx（复刻线上前缀）

想让本地也走 `/hearth/` 前缀，在**真实终端**里跑：

```powershell
powershell -ExecutionPolicy Bypass -File .\ops\local-nginx.ps1 -Action start
```

然后把 ENV 换成能指向 `http://127.0.0.1:8081/hearth` 的档位。
日常开发不需要，只在排查「前缀是否剥对」时用。

## 六、调试与排错

### 6.1 三个必看的面板

| 面板 | 看什么 |
| --- | --- |
| **Console** | 报错、`console.log` 输出 |
| **Network** | 每次请求的 URL、状态码、响应体；**脱敏验证靠它** |
| **AppData** | 页面 data 当前值 |

### 6.2 常见报错对照表

| 报错 | 原因 | 处置 |
| --- | --- | --- |
| `未找到 app.json` | 导入的目录不对 | 选 `miniprogram/` 这一层 |
| `不在以下 request 合法域名列表中` | 没勾「不校验合法域名」 | 见 4.1 |
| 请求超时 / 连接被拒 | 真机用了 127.0.0.1，或防火墙拦了 | 见 4.2 |
| `401` | 没登录或 token 过期 | 正常，会静默重登（C0 之后） |
| `403` | openid 不在白名单 | 找管理员在 `app_user` 里加 |
| 页面白屏但无报错 | 页面路径没在 `app.json` 的 `pages` 里注册 | 加注册 |
| `app.json` 里 tabBar 图标报错 | 图标路径不对或超过 40KB | 换小图或先去掉 tabBar 图标 |

### 6.3 验证「手机号确实脱敏了」

1. 打开 Network 面板
2. 找任意返回学员数据的请求
3. 看响应体里的 `mobile` 字段

**应该只出现 `136****5177` 这种形式**。出现完整 11 位就是 bug，立刻停下来修。

## 七、预览 → 真机 → 体验版

### 7.1 预览（开发版，手机上点开）

点工具栏 **「预览」** → 生成二维码 → 手机扫码。

- 只有**项目成员/体验成员**能打开
- 有效期短，适合自己看效果

### 7.2 真机调试

点 **「真机调试」** → 扫码。

- 能看到手机端的 Console 和 Network（这是排查真机问题最有效的方式）
- 记得先改 `env.js` 到 `devip` 档

### 7.3 上传体验版

1. 点工具栏 **「上传」**
2. 填版本号（例如 `0.1.0`）和备注（例如 `P0 诊断页`）
3. 上传成功后，去 **微信公众平台 → 管理 → 版本管理**
4. 找到「开发版本」→ 点 **「选为体验版」**
5. 在 **「成员管理」→ 体验成员** 里加人（柒柒、三水）

**体验版的特点**：

- 免审核，只有体验成员能打开
- **会校验 request 合法域名**（和开发版不同）
- 最多 100 个体验成员

> 所以发体验版之前，必须先在公众平台配好 `request 合法域名 = https://www.huohuawd.cn`。

### 7.4 发布前检查清单

| # | 检查 | 怎么确认 |
| --- | --- | --- |
| 1 | `env.js` 已切到 `prod` | 看文件 |
| 2 | 域名已配置 | 公众平台 → 开发设置 → 服务器域名 |
| 3 | 线上接口通 | 浏览器打开 `https://www.huohuawd.cn/hearth/api/health` |
| 4 | 体验成员已加 | 公众平台 → 成员管理 |
| 5 | 手机号脱敏**在线上也验一遍** | 真机 Network 看响应体 |

## 八、和后端/服务器的对应关系（一页速查）

| 环节 | 地址 | 谁负责 |
| --- | --- | --- |
| 模拟器请求 | `http://127.0.0.1:8080/api/*` | 后端本地进程 |
| 真机请求 | `http://<电脑IP>:8080/api/*` | 后端本地进程 + 防火墙 |
| 本地 nginx（可选） | `http://127.0.0.1:8081/hearth/api/*` | `ops/local-nginx.ps1` |
| 体验版请求 | `https://www.huohuawd.cn/hearth/api/*` | nginx → 8080（ECS） |

**后端路径永远是 `/api/*`**，前缀由 nginx 剥掉——这是整套配置唯一的约定，别改。
